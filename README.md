## 🛠 Технологии внутри:

## 📦 Как запустить проект (Инструкция для бро) 👨‍💻

Чтобы всё заработало как часы, просто следуй этим шагам:

### 1️⃣ Подготовка окружения 🏗️
Сначала нужно создать и обязательно **активировать** виртуальное окружение, чтобы не засорять систему:

```bash
# Создаем окружение
python -m venv venv

# Активируем его (для Windows)
venv\Scripts\activate

# Активируем его (для Mac/Linux)
source venv/bin/activate
```

### 2️⃣ Установка библиотек 📚
Теперь, когда мы **внутри** окружения, накатываем необходимые зависимости:
```bash
pip install django gunicorn pillow
```

### 3️⃣ Запуск сервера ⚡
Всё готово! Осталось только поднять проект и проверить его в деле:
```bash
python manage.py runserver
```

# Constanta Messenger
Репозиторий проекта Constanta — веб-мессенджера, разрабатываемого на базе фреймворка Django. Проект ориентирован на обеспечение высокой скорости работы, безопасности данных и масштабируемости.
## Технологический стек
 * **Python** (версия 3.12 или выше)
 * **Django Framework** — основной бэкенд-фреймворк приложения
 * **Gunicorn** — WSGI-сервер для развертывания в продакшн-среде
 * **Pillow** — библиотека для обработки графических файлов и пользовательских аватаров
## Инструкция по локальному развертыванию
Для настройки и запуска проекта в локальной среде разработки выполните следующие шаги:
### 1. Настройка виртуального окружения
Создайте изолированное виртуальное окружение, чтобы избежать конфликтов глобальных зависимостей:
```bash
# Создание виртуального окружения
python -m venv venv

# Активация для Windows (Command Prompt)
venv\Scripts\activate

# Активация для Windows (PowerShell)
.\venv\Scripts\Activate.ps1

# Активация для Mac/Linux
source venv/bin/activate

```
### 2. Установка зависимостей
Убедитесь, что виртуальное окружение активировано, и установите необходимые пакеты:
```bash
pip install django gunicorn pillow

```
### 3. Инициализация базы данных и запуск
Выполните миграции для создания структуры базы данных и запустите локальный сервер разработки:
```bash
# Применение миграций базы данных
python manage.py migrate

# Запуск сервера разработки
python manage.py runserver

```
После успешного запуска приложение будет доступно по адресу: http://127.0.0.1:8000/
## Дорожная карта (Планы по развитию)
В планах по развитию функционала мессенджера предусмотрены следующие этапы:
 * **Сквозное шифрование (E2EE):** Внедрение протоколов сквозного шифрования для обеспечения конфиденциальности переписки.
 * **Голосовые вызовы:** Интеграция функционала для совершения аудио- и видеозвонков внутри платформы.
 * **Персонализация интерфейса:** Разработка системы кастомных тем оформления и поддержка темного режима.
